# Power-Bi-Dashboard
🚀 Patient Flow Analytics: Unclogging the Hospital Pipeline
1. The Vibe (Project Title & Headline)
Patient Flow Analytics: Unclogging the Hospital Pipe line
Forget static reports. This is a dynamic, interactive Power BI dashboard built to attack the single biggest operational headache in healthcare: patient wait time and backlog. It tells the story of the wait list—where the bottlenecks are and who's getting stuck.
2. The Why (Short Description / Purpose)
This dashboard exists to stop managers from guessing. We're providing a clear, visual diagnostic tool that breaks down the massive patient wait list volume, flags the worst-performing specialties, and tracks the historical trends that led us here. The goal is simple: faster care through smarter data.
 3. The Toolkit (Tech Stack)
Pretty straightforward build here:
Microsoft Power BI Desktop: The whole visual engine. Used Power Query to clean up the data and DAX to calculate the critical comparisons (like current vs. prior year wait lists).
The Data: A clean CSV file—the foundational source of all the flow metrics.
 4. The Source (Data Source)
The raw numbers come from an awesome dataset I snagged from a YouTube data visualization tutorial. It includes all the good stuff: monthly snapshots from 2018–2021, case types (Inpatient, Outpatient, Day Case), and specialty names. It's real-world operational data ready for a deep dive.
 5. The Breakdown (Features / Highlights)
The Problem We're Solving
Hospitals are drowning in data, but they lack clear insight into their wait list backlog. They need to know immediately if Ophthalmology is the real problem or if it's the Paediatric team. This dashboard takes the noise out and delivers that clarity.
Key Dashboard Takeaways

Wait List Check-up: The main goal is right up front: people on the list right now. We show that against the previous year to see if we're winning or losing the battle.
Case Type Split: The donut chart is brutal but honest. It shows that over $80% of the volume is tied up in Inpatient services. That’s where the bottleneck really is.
The Age of Waiting: The bar charts break down the wait list by age group and how long they've been waiting (e.g., $0-3$ months, $6-9$ months). This is crucial for resource planning.
Who's Lagging? The specialty list is ranked by average wait time. This highlights the immediate trouble spots—for example, if Ophthalmology has a much higher average wait than others, that's where leadership needs to send support.
Looking Back: The trend lines show a steady rise in Outpatient cases from 2018 to 2021. If we don't plan for that growth, the wait list is only going to get worse.
The Real Impact
This isn't just a pretty graph; it's a tool for change. The dashboard delivers fast, focused, and undeniable insights that empower hospital ops teams to:
* Prioritize resources to the specialties with the longest wait times.
* Validate whether past operational changes actually reduced the overall backlog.
* Proactively staff for the growing demand we see in the Outpatient trend lines.
